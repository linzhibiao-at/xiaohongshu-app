# 对标拆解

## 目标

回答两个问题：
1. 用户的账号在 **3-12 个月内能到达什么水平**？
2. 达到那个水平需要复制哪些结构、放弃哪些幻想？

对标不是抄标题，是拆解"流量从哪来"。

## 选谁做对标

三个位置，各选 1 个，不要选 5 个同级账号：

| 位置 | 粉丝量级 | 作用 |
|---|---|---|
| 上位 | 5-20 万 | 看这个赛道的天花板形态与变现方式 |
| 同位 | 1-5 万 | 看可复制的选题结构与更新节奏（最重要） |
| 近位 | 0-1 万 | 看新号怎么起量，最容易直接抄结构 |

粉丝量级来自 `benchmark pick` 的 `tiers_available`，不要凭感觉猜。

## 命令序列

```bash
# 命令都在 growing 根目录（有 SKILL.md 那层）执行
# 1. 分层挑账号
python3 scripts/growing_cli.py benchmark pick --lane 母婴育儿 --per-tier 2

# 2. 逐个拆解（每个账号一次，别并发）
python3 scripts/growing_cli.py benchmark author --user-id <uid> --lane 母婴育儿

# 3. 如果已登记自己的账号，直接看差距
python3 scripts/growing_cli.py benchmark gap --user-id <uid> --lane 母婴育儿
```

如果 `benchmarks` 为空，说明采集时没带 `--with-authors`：
```bash
python3 scripts/growing_cli.py collect lane --lane 母婴育儿 --with-authors --author-top 6
```

## 怎么读输出

| 字段 | 含义 | 判断标准 |
|---|---|---|
| `summary.median_liked` | 单篇中位点赞 | 和用户当前水平比，差 2 倍以内才算"够得着" |
| `summary.viral_rate` | 爆款率 | >20% 说明选题稳定，值得抄结构 |
| `summary.fan_efficiency` | 中位赞/粉丝 | 越高说明内容效率越高，粉丝质量好 |
| `summary.median_collect_ratio` | 收藏/点赞 | >0.6 说明实用型账号，内容能长尾 |
| `pillar_matrix` | 内容支柱 × 数量 × 中位赞 | **最重要**：找出对方真正的流量支柱 |
| `title_hooks` | 标题钩子命中率 | 高频钩子就是这个赛道的通用语言 |
| `cadence.updates_per_month` | 月更篇数 | 用户能不能跟上，决定排期密度 |
| `type_mix` | 图文/视频分布 | 视频占比高 → 复制成本高 |
| `tag_usage` | 高频话题 | 可直接用于自己文案的话题池 |
| `copyable` | 可复制清单 | 含 evidence 与 how，直接转给用户 |
| `not_copyable` | 不可复制清单 | 必须讲清楚，否则用户会盲目模仿 |

## 拆解的核心动作

### 1. 找流量支柱

看 `pillar_matrix`：**占比高 + 中位赞高** 的支柱才是对方的基本盘。
只有占比高但中位赞低的，是"填充内容"，不要学。

### 2. 找选题公式

把 `title_hooks` 前 2 个钩子 + `pillar_matrix` 前 2 个支柱组合，得到 2-4 个公式：
例：`数字清单 × 用品避坑` = "N 件买了就后悔的母婴用品"。

### 3. 判断可复制性

| 对方特征 | 判定 | 应对 |
|---|---|---|
| 粉丝 >5 万且内容普通 | 账号权重壁垒 | 不追同题，改做更垂直的小切口 |
| 高频出镜、家庭场景完整 | 资源壁垒 | 先做不出镜版本（清单/对比）验证选题 |
| 视频占 60%+ | 制作成本壁垒 | 同主题做图文，验证后再视频化 |
| 内容是清单/攻略且数据好 | 无壁垒 | 优先抄，换人群或换城市重做 |

## 常见错误

- **只挑大号**：10 万粉账号的内容结构对新人无效，权重差异太大。
- **抄标题不抄结构**：标题是结果，结构（支柱+钩子+信息密度）才是原因。
- **忽略更新节奏**：对方月更 15 篇，用户每周 3 小时，排期必须按用户产能设计。
- **把"不可复制"说成"不用管"**：必须给出替代方案，否则用户会照抄失败。
