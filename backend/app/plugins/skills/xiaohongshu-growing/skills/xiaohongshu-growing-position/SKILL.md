# 定位与账号装修

## 目标

把"我要做母婴"这种方向，变成一句能让陌生人 3 秒记住的话，并落成可执行的账号装修。

定位不靠文案修饰，靠 **收窄**：人群越具体，人设越可信，内容越好生。

## 定位四切口（必须选一个主导切口）

| 切口 | 做法 | 例（母婴） | 优 | 劣 |
|---|---|---|---|---|
| 人群切口 | 锁定一个具体人群 | 只服务 0-12 月龄的新手妈妈 | 粉丝精准，转化高 | 天花板低 |
| 场景切口 | 锁定一个高频场景 | 只做"工作日 20 分钟的辅食" | 内容易系列化 | 需要场景稳定 |
| 价格带切口 | 锁定预算范围 | 只推荐 200 元以内的母婴用品 | 对比类内容强 | 易被大牌合作挤压 |
| 身份切口 | 用真实身份背书 | 三甲医院护士妈妈的护理记录 | 信任度最高 | 需要真实身份 |

**不要同时占两个以上切口**，否则定位失效。次级切口可以出现在内容里，但不写进简介。

## 三件套怎么写

### 1. 我是谁（身份 + 一个可信背书）

- 结构：`真实身份 + 一个可验证的细节`
- 好：`二胎妈，老大 4 岁老二 8 个月，都是自己带的`
- 差：`热爱生活，喜欢分享`

### 2. 为谁服务（人群 + 具体处境）

- 结构：`人群 + 当下最难的那件事`
- 好：`帮 6-12 月龄宝宝的妈妈解决"不知道每天做什么辅食"`
- 差：`分享育儿经验`

### 3. 给什么（稳定承诺）

- 结构：`频率 + 交付物 + 不做什么`
- 好：`每周 3 条可直接照着做的辅食搭配，不接广告不推杂牌`
- 差：`分享好物和日常`

## 账号装修

| 项 | 要求 | 反例 |
|---|---|---|
| 昵称 | 6-10 字，含一个身份词或人群词 | `小仙女`、`xx的日常` |
| 简介 | 三件套压缩到 3 行，第一行给你是谁 | 空简介 / 一堆 emoji |
| 头像 | 真人或强场景实拍，能看清 | 网图、风景、卡通 |
| 封面风格 | 固定 2 种版式：实拍 + 3-6 字大标题 | 每篇风格都不同 |
| 首篇人设稿 | 讲清"为什么开这个号 + 你会看到什么" | 直接发干货 |

## 首篇人设稿的写法

结构固定四段，不要写成长篇自我介绍：

```
1. 触发点：一句具体的处境（我做这个号，是因为……）
2. 我能给什么：3 条内容承诺，每条对应一个支柱
3. 我的边界：不做什么（不卖课/不接杂牌/不晒娃到隐私）
4. 互动：问一个"你正卡在哪"的具体问题
```

长度 300-500 字，配 3-6 张真实场景图，不用精修。

## 输出模板

```markdown
## 一句话定位
帮 6-12 月龄宝宝的新手妈妈，每周拿到 3 个能直接照着做的辅食搭配。

## 三件套
- 我是谁：...
- 为谁服务：...
- 给什么：...

## 主导切口
人群切口（0-12 月龄）+ 场景切口（工作日 20 分钟）作为次级

## 账号装修
| 项 | 方案 | 理由 |
|---|---|---|
| 昵称 | xx妈的小碗 | 身份词 + 记忆点 |
| 简介 | 三行文案（直接可粘贴） | — |
| 头像 | 拍宝宝餐盘 + 手部 | 不出镜但有人味 |
| 封面 | 左图右字的双版式 | 手机端可读性最高 |

## 首篇人设稿
（完整文案，已通过 copy check）

## 定位自检
- [x] 陌生人能一句话复述
- [x] 同行能说出我和他的区别
- [x] 有明确不做什么
- [x] 能被搜索命中（含人群词/月龄词）
```

## 定位自检的四个标准

交付前必过，任何一条不过就重做：

1. **可复述**：让用户念给朋友听，朋友能转述出来。
2. **可区分**：和 3 个对标账号比，能说出"我和他们的差别在哪"。
3. **可搜索**：简介里至少含 1 个人群词和 1 个场景词。
4. **可执行**：按这个定位，下周就能拍出 3 条内容。

## 常见错误

- **定位过宽**："母婴育儿"是赛道，不是定位。
- **形容词堆叠**："温柔坚定、科学育儿、松弛感妈妈"——没有一个词能被验证。
- **人设虚构**：编造身份或经历，一旦被追问就会崩塌，且内容没有细节支撑。
- **装修与内容脱节**：简介说"只做辅食"，前面 10 篇全是好物，账号标签会乱。
- **首篇发干货**：没有身份交代，后续所有内容的可信度都打折。
