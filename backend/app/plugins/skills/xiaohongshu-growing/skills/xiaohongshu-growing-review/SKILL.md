# 数据复盘

## 目标

回答三个问题，多一个都不要答：
1. 哪条有效、哪条无效？（用赛道基准判断，不是用感觉）
2. 无效的原因是流量、收藏还是讨论？（三者修法完全不同）
3. 下周**只改一件事**，改哪个？

## 命令序列

```bash
# 命令都在 growing 根目录（有 SKILL.md 那层）执行
# 0. 先刷新自己账号的最新数据（每次复盘都要做）
python3 scripts/growing_cli.py profile-set --url "<自己的主页链接>"   # 首次
python3 scripts/growing_cli.py collect refresh                        # 日常

# 1. 阶段复盘
python3 scripts/growing_cli.py review weekly --plan-id <id>

# 2. 单篇诊断
python3 scripts/growing_cli.py review note --feed-id <note_id> --lane 母婴育儿
```

单篇复盘需要该笔记已在本地库：
```bash
python3 scripts/growing_cli.py collect detail --feed-id <id> --xsec-token <token>
```

## 复盘节奏

| 时机 | 看什么 | 不要看什么 |
|---|---|---|
| 发布后 2 小时 | 是否进入推荐（曝光有没有起） | 互动数（太早，无意义） |
| 发布后 72 小时 | 点赞量级、收藏赞比 | 粉丝数（短期波动大） |
| 发布后 7 天 | 长尾表现、搜索流量占比 | — |
| 每 7 篇后 | 支柱胜负、标题钩子命中 | 单篇细节 |

## 怎么读输出

### 单篇（`review note`）

| 字段 | 含义 | 判断 |
|---|---|---|
| `percentile_in_lane` | 该篇在赛道样本中的百分位 | <0.3 偏低，>0.7 优秀 |
| `metrics.collect_ratio` | 收藏/点赞 | 高于基准 1.3 倍 → 实用价值被认可 |
| `metrics.comment_ratio` | 评论/点赞 | 低于基准 0.6 倍 → 缺讨论钩子 |
| `baseline.median_liked` | 赛道中位赞 | 这是"及格线"，不是"目标" |
| `baseline.viral_threshold` | 赛道爆款门槛 | 超过它才算爆款，才有系列价值 |
| `diagnosis` | 自动诊断结论 | 逐条转述给用户 |
| `actions` | 建议动作 | 挑 1-2 条执行，不要全做 |
| `growth` | 多次快照的增长 | `available:false` 说明只采了一次，需隔天再采 |

### 阶段（`review weekly`）

| 字段 | 含义 |
|---|---|
| `completion.rate` | 排期完成率，<80% 时"更新不稳定"是第一问题 |
| `stats.median_liked` | 自己单篇中位赞 |
| `baseline.median_liked` | 赛道中位赞（对照） |
| `pillar_rank` | 支柱胜负排名，第一名且样本 ≥3 才可信 |
| `verdict` | 阶段结论 |
| `next_actions` | 下一步动作清单 |

## 诊断决策树

按顺序判断，命中即停，不要同时改多个变量：

```
流量低（百分位 <0.3）
├─ 曝光就少 → 封面 + 标题钩子（改这两项，正文不动）
└─ 曝光有但点进来少 → 封面承诺与标题不一致

流量正常但收藏低（collect_ratio < 基准 0.6）
└─ 内容"看过就好" → 补可执行步骤/价格/参数/清单

流量正常但评论低（comment_ratio < 基准 0.6）
└─ 缺讨论入口 → 结尾换成二选一提问，正文留一个"争议点"

收藏高但流量低（长尾型）
└─ 正常现象 → 保持同题材做系列，不要为了流量改方向

各项都高但粉丝不涨
└─ 人设缺失 → 补人设篇，简介与封面加入身份信息
```

## 一次只改一个变量

排期执行期最常见的错误是"这篇数据不好，下篇又换封面又换选题又换发布时间"，
结果三周后完全不知道哪个变量起了作用。

规则：
- 连续 **3 篇** 保持同一变量组（封面风格 + 标题钩子类型），只换选题
- 3 篇后再换下一个变量
- 每次改动记在 `plan_items.note` 里，复盘时可回溯

## 输出模板

```markdown
## 结论先行
这一周 5 篇里 1 篇达标（超过赛道中位 xxx 赞），胜出方向是「用品避坑」，
问题不在选题而在封面点击率。下周只改封面，不改选题。

## 数据
| 指标 | 本周 | 赛道基准 | 差距 |
|---|---|---|---|
| 单篇中位赞 | 320 | 1800 | -82% |
| 收藏/点赞 | 0.71 | 0.52 | +37% |
| 评论/点赞 | 0.02 | 0.05 | -60% |
| 完成率 | 5/5 | — | — |

## 诊断
- 【数据】流量未起：中位 320 赞，不到赛道中位一半
- 【数据】收藏赞比反而高于基准：内容本身是"有用的"，问题在入口
- 【数据】评论占比极低：正文没有讨论入口
- 【经验】收藏高 + 流量低，通常是封面没让人想点进来（待验证）

## 下周只改一件事
封面：统一为"实拍 + 3 字大标题 + 数字"，其余保持不变。

## 需要补采
- 关键词「宝宝辅食 6个月」样本不足，建议补采 12 条
```

## 常见错误

- **只和爆款比**：和赛道中位数比才能知道自己是"正常"还是"异常"。
- **拿粉丝数当唯一指标**：起号期粉丝滞后，内容指标才是先行信号。
- **一次改五个变量**：无法归因，等于白测。
- **样本不足就下结论**：支柱只有 1 篇说"这个方向不行"，是误判。
- **忽略完成率**：断更导致的流量下滑，会被误判成"选题不行"。
