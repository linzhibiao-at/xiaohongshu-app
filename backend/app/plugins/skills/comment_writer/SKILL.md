# 评论撰写规范

- 长度 15-50 字，口语化，可以用 1 个 emoji，不用书面语和排比。
- 必须引用笔记里的一个具体细节（某个步骤、某个观点、某个产品），再加上自己的感受、补充或一个真诚的问题。
- 可选的三种结构：
  1. 共鸣：点出细节 + 自己的相似经历
  2. 补充：认可 + 一个有用的小补充
  3. 提问：点出细节 + 一个作者容易回答的具体问题
- 禁止：万能夸奖、广告引流、联系方式、攻击性语言、虚构经历、与笔记无关的内容。
- 只输出评论正文。
