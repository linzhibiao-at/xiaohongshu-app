# 宣传海报技能 (Promotion Poster Creator)

一键生成产品宣传海报或销售战报宣传海报。输入产品名称/描述或销售数据/表彰信息，自动生成专业级 AI 海报图。

> 设计方法论提炼自专业海报设计教程（布局/色彩/光线三支柱）+ 外部作图 Skill 考察精华（五要素对齐/原子块/反模式闸门/风格库）+ 安踏系列海报实战经验沉淀。
> **核心原则（灵活自由）**：用户指定什么风格/配色/版式就用什么，方法论只保证"下限不烂、结构清晰、验收有据"，不束缚创意。品牌预设（安踏红金等）仅当用户明确指定时启用，绝不默认强加。

## 先决条件

本机没有 `canvas-designer`，也没有 `sdk.tool` / `run_sdk_snippet`。出图链路固定为两步：

| 步骤 | 用什么 | 说明 |
|---|---|---|
| 生成底图 | `ImageGen` 工具 | 系统内置，直接调用，无需额外加载技能 |
| 叠加文字 | `scripts/do_text.py` | 中文零乱码，字体自动跨平台查找 |

> **本文件已按本机环境改造，并已脱离技能市场管理**（`.skill-manifest.json` 已移除），
> 平台不会再用官方版自动覆盖它。原版依赖的 `canvas-designer` + `run_sdk_snippet` 本机都不存在，
> 现改为底图走 `ImageGen`、文字走 `do_text.py`。
> 若以后手动重装了同名技能，按两条检查：Step 4 标题应为「生成无字底图」，全文不应出现 `tool.call`。

## 商业级海报设计方法论（核心）

> 一段好的海报提示词 = 把脑子里的想法说清楚：**主体是谁、重点在哪里、画面给人什么感觉、哪些必须保留、哪些绝对不要**。设计语言（布局/色彩/光线）由 AI 补充，但"观众应该先看什么"由你决定。

### 海报三要素总纲：底图 · 光 · 字

一张海报的根就三个东西，**任何一张海报都按此三要素落位，缺一不可**：

| 要素 | 是什么 | 本技能对应能力 | 验收一句话 |
|:---|:---|:---|:---|
| **底图** | 主体 + 背景 + 质感（产品/人物/场景，干净有层次、无廉价塑料感） | 五要素对齐定主体（Step 0）→ 原子块提示词【主体与核心】【布局】（Step 3）→ 6类海报场景/10风格库 | 主体唯一视觉核心、背景有质感有层次 |
| **光** | 画面唯一光源，塑造主体、统一层次与情绪 | 光线原则 + 高级感四层之"光影统一" + 调性参数表光源列 | 光从哪来答得上、处处服从同一盏灯 |
| **字** | 文字即图形：零乱码、有层级、有排版规范 | 文字双轨方案（路径A/B）+ 文字布局设计规范（references/typography.md）+ do_text.py 叠字 | 零乱码、层级分明、对齐统一、无遮挡 |

**执行顺序**：先定**底图**（主体+背景+预留区）→ 再定**光**（光源方向/颜色，写进 prompt 并贯穿文字受光）→ 最后落**字**（按文字布局规范叠字/直出，受光跟随光源）。三要素缺一个就不是合格海报；前面所有方法论都是为把这三样做扎实服务。

### 设计三支柱：布局 · 色彩 · 光线

每张海报在写提示词前，必须先在头脑中（或与用户讨论中）回答这三个问题：

| 支柱 | 要解决的问题 | 快速自查 |
|:---|:---|:---|
| **布局** | 观众应该先看哪里？文字、色块、留白如何共同突出主体？ | 有没有唯一视觉核心？阅读顺序是什么？ |
| **色彩** | 如何让不同元素保持统一，避免杂乱、发脏、廉价感？ | 全图有几种主色？是不是同色系？ |
| **光线** | 怎样塑造主体、建立视觉焦点、空间层次和情绪？ | 光从哪里来、承担什么作用？ |

### 高级感四层标准（判断"土不土"的根本框架）

> 融合「设计调性引擎」核心理论。用户说"高级一点/有设计感/还是觉得土"时，逐层对照，不要凭感觉说"好看/土"。**越底层越决定高级感。**

| 层 | 标准 | 判断心法 | 反面（=土/贴/平/乱） |
|:---|:---|:---|:---|
| **1 光影统一**（最致命） | 画面有**唯一光源**：文字受光面、人物轮廓光（Rim Light）、背景高光、阴影方向全部服从它 | 遮住画面问"光从哪来"？答不上=贴图；答得上一盏灯且处处一致=高级 | 文字纯白平贴、人物平光、倒影孤立、背景光束与人物受光面矛盾 |
| **2 质感情绪** | 画面有温度/现场感，不是塑料感 | 质感=情绪：做旧喷漆=街头；颗粒+暗角=电影；景深+丁达尔=现场 | 纯色平滑背景+系统黑体=塑料感/贴纸感/模板感 |
| **3 动态叙事** | 构图是"正在发生"的瞬间，视线被牵着走 | 视线路径=大字→人物眼神/手势→标语 | 元素平铺、无主次、无动势 |
| **4 色彩克制+字体定制**（最表层最直观） | ≤3 色（1主色+1强调色+中性色）；字体有定制感（关键词变色/做旧） | 多色堆=乱；整篇同字号同色系统黑体=模板感 | 超过3色、多素材硬拼、字体零定制 |

**8 个可操作决策**（拿到命题后逐项填，"高级感"不是形容词而是决策）：

| # | 决策 | 旧做法（贴/平） | 设计师做法 | 落地方式 |
|:--|:--|:--|:--|:--|
| 1 | 构图 | 水平左文右人 | 文字斜切+动势 | prompt 声明"标题倾斜"/PIL 旋转 |
| 2 | 文字即图形 | 系统黑体零处理 | 做旧喷漆+飞白 | PIL 噪点+threshold 飞白 |
| 3 | 文字衬底 | 无 | 关键词背后喷溅/笔触 | PIL 叠半透明喷溅贴图 |
| 4 | 关键词变色 | 整篇同色 | 关键词单独强调色 | PIL 分字渲染，只1-2字上色 |
| 5 | 单光源 | 光从哪来答不上 | 唯一舞台光 | prompt 声明唯一光源（方向/颜色/强度） |
| 6 | 轮廓光 | 人物平光 | 发丝/肩 Rim Light | prompt 声明人物轮廓光 |
| 7 | 背景层次 | 光束+网格+噪点硬拼 | 舞台景深虚化（bokeh） | prompt 声明景深+散景，一个逻辑 |
| 8 | 色彩克制 | 多色堆 | 黑红白三色 | 锁定 1主色+1强调色+中性色 |

**分工原则**：#5/6/7/8（光影、背景、色彩、动势）交给 AI 出图写进 prompt；#1/2/3/4（文字处理）AI 做不了（中文必乱码），交给 PIL 后期（见 Step 5 的 do_text.py）。

### 布局原则（解决"先看哪里"）

1. **视觉聚核**：单一主体海报，所有元素（文字、色块、留白、辅助元素、光影）都把视线**推向同一个核心**。主体是唯一绝对视觉中心，不建立第二焦点。
2. **Typography 参与构图**：超大文字可以成为"视觉色块"（巨型标题、竖向英文），而不只是说明文字——它是构图的一部分，要有存在感但不抢主体。
3. **不对称平衡**：避免主体死板居中。经典编辑式结构：左侧巨型 Typography + 右上中文标题 + 中下部主体 + 右下日期信息，形成稳定而有张力的不对称平衡。
4. **明确阅读顺序**：主动设计"第一眼→第二眼→第三眼"。例：第一眼主体文物 → 第二眼圆环与 Typography 的向心关系 → 第三眼标题与展览信息。把阅读顺序写进提示词。
5. **文字分区**：信息只集中在几个明确区域（如左侧、右上、右下），**不平均撒满画面**，保留足够负空间（留白）。
6. **单焦点 + 装饰克制**：装饰元素（圆环、线条、光效）只承担"向心、托住核心"的作用，不能成为独立视觉中心。

### 色彩原则（解决"干净不廉价"）

1. **同色系高级渐变是万能的"干净"秘诀**：画面脏、杂、乱，几乎都是色彩约束没做好。把"五彩斑斓"改为**同一色系内的深浅渐变**（如：乳白→燕麦米→香槟金；深蓝→藏青→黑），画面立刻干净统一有高级感。
2. **色彩定量约束**：在提示词里明确写"全图严格控制在 [主色A + 主色B + 主色C] 三种主色以内"，只允许强调色少量点缀。例：唐碗海报 = 深绛红 + 古金 + 暗棕黑 + 少量朱红。
3. **低饱和、低对比、留白充足** = 高级感。浓艳高饱和 + 满版元素 = 廉价感。
4. **金色慎用**：金色要低饱和、局部点睛（大数字、姓名、标题高亮），**禁止大面积亮金**（"亮黄色大面积金色"是廉价感头号来源）。安踏系列实证：金色 #ffd76a 微光晕点缀数据与姓名。
5. **同系列调性锁定**：一个系列的多张海报（封面/banner/开屏）必须共用同一套配色与视觉基准。生成衍生尺寸时，把配色基准图放 `reference_images` 第一位，并强调"严格采用第一张图完全相同的配色方案和视觉调性，不要压暗、不要去掉光束、不要降低饱和度"。**不要自作主张改变用户确认过的配色。**

### 光线原则（解决"层次与情绪"）

1. **光线塑造主体，不只是照亮**：一束光可以切割画面、引导视线、制造速度感、建立空间层次。例：一道锐利光束水平穿过人物眼睛，其余部分沿同方向形成运动轨迹。
2. **保留视觉锚点**：找到画面最出彩的局部（产品高光 / 人物眼睛 / 数据区），让光线强化这个锚点。
3. **光效是氛围不是主角**：背景光束/光晕做背景层次，不能抢主体；光效延伸到画面边缘属正常设计元素（不视为"贴边"缺陷），但**用户明确反对贴边时以用户当次指令为准**。
4. **唯一光源**（最高优先级）：全图只允许一盏"灯"，文字受光、人物轮廓光、阴影方向全部指向它。多光源=廉价感。要写进 prompt：光源方向（右上/顶部/侧上）+ 光源颜色 + 强度。

### 调性参数表（"高级感"的 4 个可调旋钮）

拿到命题后先定调性：**情绪 + 1 个主色 + 1 个光源方向 + 1 个质感关键词**。换调性只改这 4 个参数，prompt 结构不变：

| 调性 | 情绪 | 主色（≤3色） | 光源 | 质感关键词 |
|:---|:---|:---|:---|:---|
| 街头潮流 | 酷/真实/现场 | 黑+深红+白 | 右上红舞台光 | 做旧喷漆/喷溅/景深/颗粒 |
| 科技数据 | 理性/未来 | 深蓝+青+白 | 侧上冷光 | 全息网格/粒子/微光晕 |
| 高端商务 | 稳重/贵气 | 炭黑+香槟金+白 | 柔和顶光 | 磨砂哑光/细描边/大留白 |
| 温暖人文 | 暖/亲近 | 暖米+古铜金+白 | 柔和侧光 | 暖调/柔和光晕/细颗粒 |
| 运动活力 | 热血/爆发 | 黑+安踏红+白 | 顶部聚光 | 动感光轨/速度线/锐利高光 |

> 注：科技数据调性的"全息网格"只在明确要赛博/数据感时用；**普通商务/荣誉海报禁用放射线+地面网格**（见反模式清单）——这是"5-8年前PPT旧调性"的最大标志。

## 工作流程

### Step 0: 五要素对齐（先对齐，再出图）

生成任何图之前，先确认 5 项要素。**关键项（平台/比例、标题文字、视觉主体）缺失必须停下来问，不猜**，不做"抽奖式"出图；次要项（情绪、禁用元素）缺省用合理默认值并在交付时说明。

| 要素 | 说明 | 示例 |
|:---|:---|:---|
| 平台/比例 | 决定画幅（见「图片尺寸」表；小红书 3:4、抖音 9:16、公众号 16:9、方版 1:1） | 手机海报 9:16 |
| 标题文字 | 主标题**逐字给出**，AI 才准确渲染，防被"二创"改写 | 「月度销售冠军榜」 |
| 视觉主体 | 画面中心元素（人物/产品/场景/抽象概念） | 导购与顾客社群互动 |
| 情绪 | 想传达的气质（专业/活力/温暖/冲击/克制） | 热血+荣誉 |
| 禁用元素 | 明确不能出现的东西（用户指定才禁，没说就自由） | 不用蓝色、不出现其他品牌logo |

> 关键项缺失用 `ask_user` 补问一次；用户已给的信息直接用。

### Step 1: 收集基础信息

写提示词前，先确认必要信息（用户已给的直接使用；关键项按 Step 0 补齐，次要用合理默认值填充并在交付时说明）：

- 海报主题 / 类型（产品功能、新品发布、销售战报、荣誉表彰、活动促销、社媒封面）
- 中文标题、是否需要英文标题
- 主体：产品（用 `web_search` 搜索真实产品信息与核心卖点，不编造参数）或 人物 / 数据
- 必要信息：时间、地点、价格、数据指标、人名头衔等
- 海报比例（见「图片尺寸」表，默认 9:16 竖版手机海报）
- 参考图 / 参考风格（有则先用 Read 工具打开图片，读出内容与尺寸）
- 用户口述的：**必须保留什么、绝对不要出现什么**

> 不要为用户没提的设计问题反复追问——用下述方法论自主做出合理的设计决策，一次交付。

### Step 2: 确定设计方向（布局/色彩/光线三选一或组合）

**有参考图时（最高效路径）**：把参考图信息告诉 AI/用户——*这是什么、想做成什么、最想保留什么、最不希望出现什么*——反推这张图适合哪种布局、哪套色彩、哪种光线，再从两个方向中选一个细化。

**无参考图时**，按海报类型默认方向：
- 产品功能海报 → **布局**（视觉聚核，产品45°展示）+ **色彩**（品牌同色系渐变）+ **光线**（产品高光聚焦）
- 销售战报/表彰海报 → **布局**（数据聚核，金数点睛）+ **色彩**（蓝金受控撞色或红金）
- 活动促销海报 → **布局**（CTA 焦点）+ **光线**（聚光产品）+ **色彩**（高饱和但同色系内）
- 课程/培训海报 → 大量精确文字用「AI 无文字背景底图 + PIL 程序叠加文字」双轨方案（见 Step 5）

确定后，在心里设计**阅读顺序**（第一眼→第二眼→第三眼），下一步写进提示词。

### Step 3: 构建海报提示词（统一骨架）

**先决定文字路径（二选一，写提示词前必须定）：**
- **路径 A「AI 直出字」**：文字少（主标题+1-2处），AI 直接渲染文字 → 用下方完整骨架（含【文字内容】）。
- **路径 B「无字底图+PIL叠字」**：文字多、要高级感、要零乱码 → 骨架中**删除【文字内容】区块**，改为【文字预留区】明确分区（见下），AI 只出无字底图，文字用 `scripts/do_text.py` 程序叠加。**选 B 时 prompt 末尾必须写"画面不出现任何文字，文字另行程序叠加"，否则 AI 会自行加字导致与程序叠字重叠。**

所有海报提示词使用以下骨架，按海报类型填参数（路径 B 删【文字内容】换【文字预留区】）。骨架即**结构化原子块（Prompt as Code）**：每个【区块】独立可改可复用，批量生产只换主体/标题/情绪参数；标题必须**分行逐字**写出（第一行「…」第二行「…」），锁定不被 AI 二创改写。

```
[海报类型] + [高级感气质定位]：一张[气场描述，如：具有当代美术馆编辑感 / 高端运动品牌广告感 / 数据战报荣誉感]的[海报类型]海报，[比例]构图。

【主体与核心】
[主体]是画面唯一绝对视觉核心，位于[位置]，[尺寸描述]，[保留真实材质/细节：如金属磨损、织物纹理、产品结构线]，采用[质感：博物馆藏品摄影 / 高端产品摄影]，避免[廉价感来源：3D塑料感/商业渲染感]。

【布局】
构图采用[视觉聚核 / 左文右人 / 不对称平衡]：[具体布局描述——文字、色块、留白、辅助元素如何把视线推向核心]。
文字分区：信息只集中在[哪个区域]，不平均撒满画面，保留[多少]负空间。
Typography：[主标题]超大字号作[视觉色块/视觉重心]，位于[位置]；[辅助文字]小字号；字体气质[高对比衬线/现代无衬线/黑体加粗]。

【色彩】
全图色彩严格控制在 [主色A] + [主色B] + [主色C] 以内，[同色系渐变方向描述]，[强调色]仅少量点缀。整体[沉稳/高贵/活力/干净]。[若是系列物料：严格采用基准图相同配色与调性]。

【光线】
[主光方向与类型]，[光效承担的作用：聚焦主体/切割画面/引导视线/营造氛围]，[光晕或光束位置]，不过度发光。

【文字内容】（路径 A 用；只写以下要显示在画面中的文案，逐条列出，出现且只出现这些）
- 主标题：...
- 副标题：...
- 数据：...
- 人员信息：...
- 时间地点/价格/CTA：...
- 底标/口号：...

【文字预留区】（路径 B 用；替代文字内容区块）
- 上部[0-30%高度]：主标题预留区，必须纯净暗色、无任何装饰元素
- 中部[35-60%高度]：核心数据预留区，必须纯净、无光轨/杂物穿过
- 下部[65-90%高度]：辅助信息预留区，保持干净
- 所有预留区不得出现任何元素穿过，文字将程序叠加在这些区域

【阅读顺序】
第一眼：[主体]，第二眼：[向心视觉关系]，第三眼：[标题与信息]。

【避免】
主体死板居中；多个视觉中心；文字平均撒满；装饰元素抢主体；浓艳配色；大面积亮金；过度发光；3D渲染感；错别字乱码；文字变形；把设计指令/括号备注渲染进画面；水印。
```

**产品功能海报的关键参数**（安踏系列实证）：背景深色渐变（深蓝→黑/科技红）+ 聚光灯 + 产品45°展示 + 卖点标签 + 科技光效；主标题超大加粗发光；数据金色 #ffd76a 微光晕；底色高饱和但要与主色同系。

**销售战报表彰海报的关键参数**：竖版；主标题作为视觉重心；核心数据用**金色大数字（数据:说明字号比约 2.5:1）+ 白色小字 + 细竖线分隔**的三段式/卡片式横排；人物头像（如有）用白底圆形/卡片方案，不抠图；组间距紧凑，不铺散。

### Step 4: 生成无字底图

用 `ImageGen` 工具出图。Step 3 写好的 prompt 原样传入，末尾必须追加
“画面不出现任何文字，文字另行程序叠加”。

```
ImageGen(
  name="[海报名称，中文描述具体内容]",
  prompt="[Step 3 的完整提示词]。画面不出现任何文字，文字另行程序叠加。",
  size="1024x1792"   # 9:16 竖版；小红书 3:4 用 768x1024；方版用 1024x1024
)
```

- `size` 只能取枚举值，没有 `1440x2560` 这类自定义尺寸。画幅不符就靠 `do_text.py` 处理
- `ImageGen` 不接收参考图，参考图里的风格要点写进 prompt 描述
- 生成多张时 `name` 描述具体内容，不要用编号
- 图片路径以返回结果为准，不要硬编码

> 原来这一步是 `create_canvas` + `generate_canvas_images`（通过 `run_sdk_snippet` 执行），
> 本机没有这套 runtime，已整体替换。

### Step 5: 核验与文字问题处理

从工具结果获取图片路径返回给用户前，按以下清单核验：

**核验清单**：
- 文字：逐字可读、无乱码、无括号备注/设计说明被渲染进画面、无错别字缺字
- 间隔号：必须用标准居中圆点「·」（U+00B7），防止渲染成实心黑点「•」
- 层级：主标题最大、身份条/说明次之、小字可读；金色只做点睛（**字号比例/对齐/边距按「文字布局设计规范」执行，见 references/typography.md**）
- 边距：内容不贴边；手机竖版四周留 15-20% 安全边距，极扁 banner 留 3-5%
- 主标题不遮挡人物头部/产品关键部位
- **文字与背景不重叠**：叠字路径逐层检查文字是否被背景元素（光轨/装饰/杂物）穿过；AI 直出路径检查文字是否压住人物/产品
- 重复：CTA 不重复出现；同系列配色调性与基准一致

**反模式验收清单（出图后逐项打勾，命中任意一条=还没到高级感）**：

| 类别 | 检查项 |
|:---|:---|
| 模板病（AI味） | 默认紫色渐变背景（AI 最爱，非用户要求绝对禁止）；三张对称功能卡+居中hero+按钮的"万能落地页"套路；假数据感（整齐划一的头像/评价/图表）；渐变+毛玻璃+圆角卡片堆满全图 |
| 土 | 放射线+地面网格（5-8年前PPT旧调性）；金色是"油亮渐变金"（应低饱和哑光香槟金）；>3种高饱和色；大面积发光/发光重影 |
| 贴 | 文字纯白平贴无受光无投影；人物平光无轮廓光；人物脚下孤立模糊倒影；背景光束与人物受光面矛盾（光从两个方向来） |
| 平 | 背景纯色平滑无颗粒无景深；系统默认黑体零定制；整篇同字号同色无层级 |
| 堆砌 | 背景同时塞光束+网格+噪点多种素材；文字区信息堆一坨；无动势（无倾斜无引导）；左挤右空无呼吸感 |
| AI生硬 | 小字乱码粘连；手指/鞋带/鞋底模糊；水印感文字/无意义英文/括号备注或设计说明被渲染进画面；人物边缘白边/光晕（抠图不净） |
| 商标擦边 | 出现非预期 logo/对勾/商标（AI 生成商品特写最易带出，实测抓到耐克对勾）；出现用户明确禁用的任何元素 |

> **自检口诀（六问）**：光从哪来 → 有没有颗粒感 → 有没有动势 → 是不是只有3色 → 小字乱不乱码 → 有没有意外logo。六问都过才算达标。
> **一票否决**：命中任意一条 → 改 prompt 重出，**不交付次品**。

**AI 生图中文字不可靠的应对（重要，实战验证）**：
- **中文小字天然发虚**：AI 生成的小字（说明、数据标签、底标）缩小后易模糊断裂。涉及大量精确文字（课程海报/培训通知）时，改用「AI 生成无文字品牌调性背景底图 + PIL 用 Noto Sans CJK 程序叠加文字」的双轨方案，文字零乱码。
- **双轨方案（推荐给"要高级感"或文字多的海报）**：AI 生成**无文字底图**（prompt 含【文字预留区】+ 末尾写"画面不出现任何文字，文字另行程序叠加"）→ 用 `scripts/do_text.py` 程序叠字，实现零乱码 + 做旧喷漆 + 受光渐变 + 关键词变色：
  ```bash
  # 叠字示例：--light 必须等于 prompt 声明的主光源色，受光与投影方向统一跟随光源
  python3 scripts/do_text.py \
    --bg 底图.png \
    --text "主标题|副标题小字" \
    --pos 148,200 \
    --size 180 \
    --weight Black \
    --light "#FF5533" \
    --light-angle top \
    --accent "目标" --accent-color "#FF3B30" \
    --grain 0.35 \
    --out 成品.png
  ```
  `--grain` 默认 0.15（日常/生活类封面直接用默认，别手写）；上面示例的 0.35 是街头/促销风，
  这档磨损更明显但大字仍可读。小字多、要正式感的封面保持 0~0.15。
  **文字定位与遮挡检查（关键，勿跳过）**：
  1. **叠字前**：用 Read 工具打开底图看，确认【文字预留区】确实纯净无杂物；若有元素穿过预留区，重新生成底图或调整 pos 避开。
  2. **算坐标**：`pos` 是文字左上角坐标，按底图实际尺寸比例计算（如 768 宽底图，主标题 x≈64、副标题在其下方 y≈高度×0.18），不要凭感觉估。
  3. **逐层叠、逐层验**：每叠一层就用 Read 打开看一次，检查该层文字是否与背景元素重叠、是否被光轨/装饰穿过；**发现重叠立即调整 pos 或重出底图，不要全部叠完再检查**。
  4. **成品核验**：全部叠完后，整图核验文字可读性、层级、无遮挡、无乱码。
  原理：**文字不是"贴上去的黑体"，而是"图形"**——做旧飞白+受光+背后喷溅，整个场景服从一盏灯（光影统一）。这是解决"高级感"和"中文乱码"双问题的关键路径。
- **同字号控制**：AI 对"缩小字号/左移一点"等模糊指令不敏感，用可量化描述——"总宽度不超过画面宽度55%、四周留出大量空白"，或用 PIL 像素测量 + 程序缩放修正。
- **防乱码强措辞**：提示词末尾写"海报中只能出现指定的宣传文案，严禁出现任何括号备注、设计说明或提示文字"。
- **拉伸变形**：目标比例与源图不一致时禁止直接 resize（会拉长人物）——生成时在提示词里写"内容收进水平中央约80-82%、左右各留约9-10%纯渐变缓冲带"，再用 PIL 居中/按内容裁切。

### Step 6: 返回结果

把 `ImageGen` 返回的 `file_path` 和尺寸原样报给用户，不要自己拼路径。

## 文字布局设计规范（Typography，重点能力）

> 完整规范见 `references/typography.md`（字号层级比例/对齐策略/安全边距/logo组合/字体选型/文字质感分级/验收清单）。**核心：文字不是"贴上去的说明"，而是与主体同等重要的构图元素。** 以下为执行速查，做海报时按此落位：

| 规范 | 速查 |
|:---|:---|
| **字号层级** | 文案分 4 级：L1 主标题(1.0) > L3 数据/强调(0.65~0.75) > L2 副标题(0.5~0.6) > L4 说明/底标(0.3~0.35)；数据:说明≈2.5:1；**同级同字号** |
| **对齐** | 居中=品牌主视觉/正式/表彰（拿不准默认居中）；左对齐=编辑感/信息多（必须左缘成轴）；右对齐极少用 |
| **安全边距** | 竖版四周 15~20%；横版上下 3~5%、左右 5~8%；上下各 5% 为裁切禁区；文字不压主体/logo |
| **logo 组合** | 先查 logo 字体气质定标题字体（衬线logo配衬线标题）；主视觉 logo 大（160px+）；logo 与标题拉开间距防堆叠；标题分隔用品牌图形logo嵌字比居中圆点高级 |
| **字体选型** | 标题 Noto Sans CJK Black/Bold（衬线场景 NotoSerifCJK-Bold）；正文 Regular/Medium 禁全篇 Black；标题可 --spacing 2~4px |
| **文字质感** | 街头/促销重度做旧(grain 0.4~0.5)；战报中度+金色点睛(0.25~0.35)；**高端品牌/正式用干净白字+关键词色强调(grain 0~0.15)**；受光跟随主光源 |

**文字布局验收（出图后必查）**：层级分明？对齐统一？安全边距够？无遮挡？logo 组合得当？文字即图形？无多余文字？——命中未过则调整重出。

## 注意事项

- 提示词必须用**用户所使用的语言**编写
- 底图用 `ImageGen` 工具生成（无字），文字用 `scripts/do_text.py` 叠加
- **尺寸只能取 ImageGen 的枚举值**（见上表），需要精确画幅时靠 `do_text.py` 按目标尺寸重排
- 有参考图片时，先用 Read 打开看，把风格与构图要点写进 prompt
- 海报文案必须凝练：**用户说"文字太多/没设计感"时，做文字取舍，不逐条罗列**，把最有冲击力的信息放大为视觉重心
- 多张海报每张 `name` 描述具体内容，不用编号
- 生成失败就换措辞重试一次，仍失败改用 PIL 手排，不要连试三次
- 同系列物料必须锁定统一配色与调性基准，衍生尺寸以基准图为第一参考
- **高级感判断**：用户说"高级一点/有设计感/还是土"时，用「高级感四层标准」逐层对照（光影统一→质感情绪→动态叙事→色彩克制），不要凭感觉说"好看/土"；调性参数表与反模式清单见 `references/style-map.md`
- **无字底图+PIL叠字**：追求高级感或文字较多时，用「AI 无文字底图 + scripts/do_text.py 程序叠字」双轨方案（做旧+受光+关键词变色），文字零乱码且"吃"进环境光，不纯白平贴；**必须执行文字定位与遮挡检查（Step 5），逐层叠逐层验，文字与背景元素重叠是返工第一大坑**
- **字体依赖**：do_text.py 自动找中文字体，按 Noto Sans CJK → PingFang → 冬青黑体 → 华文黑体 的顺序降级；`--weight Black` 在集合字体里没有对应字重时会降一级（如 PingFang 落到 Semibold、冬青落到 W6），实际用的是哪个字体脚本会打到 stderr。要指定字体就用 `--font /path/to/font.ttc` 或环境变量 `DO_TEXT_FONT`；macOS 和 Linux 都能跑，不再需要 `fc-list`。需要 `fonttools` 才能在 .ttc 集合里定位简体 face（缺了会直接报错提示 `pip install fonttools`，不瞎猜 index 以免出繁体字）
- **文字布局**：排版不稳（层级乱/对齐散/logo组合差/字体不搭）是海报返工最大来源之一——叠字前先按「文字布局设计规范」（references/typography.md）定字号层级/对齐/边距/字体，再算坐标，不要凭感觉排
