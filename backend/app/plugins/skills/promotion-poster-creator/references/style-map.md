# 风格库（内容气质 → 视觉风格，通用映射）

> 来源：外部 Skill 考察（Punk-Skill 风格方法论）+ 实测沉淀。**配色仅为示例，不绑定任何品牌**——用户指定什么配色就用什么，本表只提供视觉规则。

## 10 种通用风格

每种风格 = 明确视觉规则 + 适配内容气质。选风格前先明确内容气质，再从「风格选择速查」定位。

| 风格 | 视觉规则 | 适配内容 | 示例配色（可自由替换） |
|---|---|---|---|
| 咨询报告视觉 | 浅底、深字、克制排版、关键词大字重构、信息分层 | 商业策略、方法论、培训课件、白皮书 | 浅灰底+深字+少量点缀 |
| 商业杂志头版 | 大标题区块+主体图、编辑设计感、clean 背景 | 品牌活动、人物专访、新品发布 | 白底+品牌主色标题 |
| 巨型透视中文标题 | 标题巨大压满画面、透视/斜切动势、强冲击 | 活动宣传、直播预告、促销 | 品牌主色底+白字 |
| 黑红剪影 | 红底黑剪影、强对比、戏剧感 | 竞技、突破、燃点营销 | 深红+黑 |
| 极简公共空间摄影 | 大留白、空间感、单一主体、克制 | 观点长文、文化观察、生活方式 | 低饱和自然色 |

## 使用规则

1. **先对内容气质，再选风格**：风格不是随便挑的，先判断内容是什么气质（策略/活动/燃/文化/教程/故事/品牌/数据），再对表选 1-2 个候选。
2. **默认给用户 2-3 个候选风格**，由用户选一个（或直接指定），不要自作主张只做一个。
3. **配色可自由替换**：表中配色只是示例。用户指定色卡（如品牌色）→ 用用户色卡；用户没指定 → 按风格示例或内容气质合理选色。
4. **风格只是下限保障**：如果用户直接指定了风格/配色/版式，以用户为准，本表仅作补充。
