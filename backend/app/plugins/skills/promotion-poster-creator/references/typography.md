# 文字布局设计规范（Typography Layout Guide）

> 来源：多轮海报实战沉淀（销售战报/品牌主视觉/封面）+ 用户迭代反馈修正。**核心：文字不是"贴上去的说明"，而是与主体同等重要的构图元素。** 所有数值为参考基准，按画幅等比缩放；用户指定排版时以用户为准（灵活自由）。

## 一、字号层级比例（先定层级，再定字号）

画幅确定后，先列全部文案并分 4 级，再按比例定字号。**层级不清=排版乱的根因。**

| 层级 | 用途 | 相对主标题比例 | 说明 |
|:---|:---|:---|:---|
| L1 主标题 | 画面第一视觉重心 | 1.0（基准） | 全图最大，只放 1 行核心信息 |
| L2 副标题/区块标题 | 第二阅读点 | 0.5~0.6 | 与主标题拉开明显差距 |
| L3 数据/强调 | 关键数字、姓名 | 0.65~0.75 | 可略大于副标题，用色/字体区别于正文 |
| L4 说明/底标 | 时间、地点、落款 | 0.3~0.35 | 可读即可，宁小勿大 |

- **竖版 1440×2560 参考值**：主标题 150~200px、副标题 80~100px、数据 100~130px、底标 45~60px。横版按宽度等比换算。
- **数据:说明字号比约 2.5:1**（销售战报实证）：数据要一眼看到，说明只做注解。
- **同层级同字号**：同级信息必须同字号同字重，否则视觉会"跳"。

## 二、对齐策略（构图气质决定对齐方式）

| 对齐 | 适用场景 | 规则 |
|:---|:---|:---|
| **居中** | 品牌主视觉、正式发布、荣誉表彰、标题短 | 主标题居中，副标题/数据沿同一中轴线对齐；主体（logo/产品/奖杯）居中或正下方；对称、庄重、稳 |
| **左对齐** | 编辑感、信息多（课程/活动）、杂志风 | 文字块左缘对齐，形成"左文右图"或"左文右下图"的不对称结构；右侧留白 |
| **右对齐** | 极少用 | 仅当主体在左时镜像使用 |

- **拿不准时默认居中**（多轮实测：左对齐若处理不当易被判"排版奇怪"，居中最稳）。
- 编辑式左对齐必须有"对齐轴"：多行文字左缘必须对齐在一条竖线上，不能参差。

## 三、安全边距与文字禁区

- **竖版手机海报**：四周留 15~20% 安全边距；**横版/banner**：上下留 3~5%，左右留 5~8%。
- **文字禁区**：画面上下各 5% 高度是裁切风险区（不同平台预览会裁），主文字不进入。
- **主体遮挡**：文字不压人物头部、产品关键部位、logo 本体。
- **文字块之间**：相邻文字块间距 ≥ 1 倍 L4 字号，避免"糊成一团"。

## 四、文字与 logo 组合（品牌主视觉高频痛点）

- **logo 优先看字体气质**：品牌 logo 是衬线体（如 KOLON SPORT）→ 标题用**衬线宋体**（NotoSerifCJK-Bold）匹配；logo 是无衬线 → 标题用粗黑。**先查 logo 字体再定标题字体**，否则显廉价。
- **logo 大小**：品牌主视觉 logo 要大（竖版主视觉参考 160px+，作为品牌锚点）；辅助出现时小（60~90px）且靠上。
- **logo 与标题必须拉开间距**：横版顶部垂直空间紧张时，logo 更小更靠上，标题单行，中间留 ≥ 1 行字高的空隙，防止堆叠挤糊。
- **品牌符号当标点**：标题中间的分隔用品牌图形 logo 嵌字（如「踏秋 [logo] 入野」）是高级做法；**纯居中圆点「·」在标题里显 low**（用户原话），信息位（如"华东大区 · 七月"）可用圆点。
- **logo 单独叠加**：程序叠字流程中，品牌 logo 用 PIL 单独按原图比例叠加（不缩放拉伸变形）。

## 五、字体选型与字重

- **标题**：Noto Sans CJK **Black**（力量/促销/战报）或 **Bold**（正式/商务）；衬线场景用 NotoSerifCJK **Bold**（高级/书卷气/山系）。
- **正文/说明**：Noto Sans CJK Regular/Medium，**禁全篇 Black**（视觉疲劳）。
- **字距**：标题可 `--spacing 2~4px` 略松显大气；正文 0。
- **英文**：与中文气质匹配（衬线配衬线、无衬线配无衬线），不混搭。

## 六、文字质感（按场景分级，勿默认重度做旧）

| 场景 | 文字处理 | 说明 |
|:---|:---|:---|
| 街头潮流/促销/燃 | 重度做旧+喷溅+受光（grain 0.4~0.5） | 有现场感 |
| 销售战报/活动 | 中度做旧+金色点睛（grain 0.25~0.35） | 数据金色 #ffd76a 微光晕 |
| 高端品牌/正式 | **干净白字+关键词色强调**（grain 0~0.15） | 用户实证：高端主视觉认可干净白字，勿过度做旧/受光 |

- **受光**：`--light` 用底图主光源色、`--light-angle` 与投影方向统一；高端场景受光减弱。
- **暗部过压**：整体偏暗时 gamma 1.2 提亮（对白字金字几乎无影响，主要提亮暗部），优于调曝光。

## 七、文字布局验收清单（出图后逐项打勾）

1. [ ] **层级分明**：L1>L3>L2>L4 视觉顺序一眼可辨，同级同字号
2. [ ] **对齐统一**：居中则全组居中、左对齐则左缘成轴，无参差
3. [ ] **安全边距**：四周 15~20%（竖版）/5%（横版），无裁切风险区文字
4. [ ] **无遮挡**：文字不与主体/logo/光轨/装饰重叠，逐层叠逐层验
5. [ ] **logo 组合**：logo 大小得当、与标题间距充足、字体气质匹配
6. [ ] **文字即图形**：有做旧/受光/变色（按场景分级），非纯白平贴系统黑体
7. [ ] **无多余文字**：画面只出现指定文案，无水印感文字/括号备注
