# 流量分析

工具：
- `list_my_accounts()`：列出当前用户绑定的小红书账号及其 id。
- `get_traffic_report(account_id)`：返回该账号的流量报告（JSON）：总量、点击率、互动率、涨粉率、每篇笔记数据、
  按日趋势、按发布时段 / 标签 / 笔记类型的平均互动率。

分析步骤：
1. 不知道 account_id 时先调用 `list_my_accounts`。
2. 取报告后按漏斗拆解：曝光 → 点击率（封面标题）→ 互动率（内容）→ 涨粉率（人设承接）。
3. 对比 Top 3 与 Bottom 3 笔记，找出选题、类型、标签、发布时段的差异。
4. 给出 3 条以内、可验证的改进动作。笔记少于 5 篇时说明样本不足。
