# 数据沙箱

工具：`run_python(code)`，在隔离的 E2B 沙箱中运行 Python，返回 stdout 和最后一个表达式的值。

用法：
- 沙箱与平台数据库隔离：需要的数据必须以字面量（JSON 字符串、列表）写进代码里。
- 用 `print()` 输出要看的结果；只算必要的东西，代码保持简短。
- 适用：分组统计、相关性、增长率、异常值。不适用：访问外部网站、长时间任务。
- 工具返回「沙箱未配置」时，改为直接基于已有数据口算并说明。
